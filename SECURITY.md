# Security Policy

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in public issues.

For repositories that support GitHub private vulnerability reporting or Security Advisories, use that private channel first.

If a private GitHub reporting channel is not available, contact:

**Mario Phillip**  
mario.phillip@digitalconveniences.com

Include enough information to reproduce and assess the issue, but do not include credentials, private keys, production secrets, or personal data unless explicitly requested through a secure channel.

## Scope

Repository-specific `SECURITY.md` files take precedence over this organization-level policy.

## Response

Digital Conveniences will acknowledge reports as practicable, assess severity and affected components, and coordinate remediation and disclosure appropriate to the issue.
